# 🧾 Freelance Project Tracker

A complete **Freelance Project Tracker** built using **FastAPI**, **SQLAlchemy**, and **MySQL**, designed to help freelancers manage clients, projects, and invoices efficiently.

---

## 🚀 Features
- Manage Clients, Projects, Developers, and Invoices  
- Authentication with JWT Tokens  
- MySQL Database via SQLAlchemy ORM  
- FastAPI backend with Jinja2 frontend templates  
- RESTful API with automatic Swagger documentation  
- Integrated with XAMPP (Local MySQL Server)

---

## 🛠️ Tech Stack
- **Backend:** FastAPI (Python)
- **Database:** MySQL (XAMPP)
- **ORM:** SQLAlchemy
- **Frontend:** Jinja2 Templates
- **Environment Config:** python-dotenv
- **Server:** Uvicorn
